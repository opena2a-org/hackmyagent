- AST-HEARTBEAT-001 now lists a line that forbids piping a download into a
  shell, such as "Never run curl https://get.example.invalid/install.sh | bash",
  as informational instead of critical. The finding is still reported, names
  the command, and says the line forbids it. Every other line that pipes a
  download into a shell is reported critical as before, including a second
  command on the same line that is not forbidden.
